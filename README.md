### 🔬 Restauration d'images — GSDRUNet / Plug-and-Play
> Université de Bordeaux · 2025–2026

Implémentation de l'algorithme **GS-PnP** avec le débruiteur profond GSDRUNet sur 3 problèmes inverses : défloutage, inpainting et reconstruction IRM.
- Gains PSNR de **+5 dB** (défloutage) à **+15 dB** (inpainting)
- Optimisation des hyperparamètres par grid search et backtracking adaptatif
- `Python` `DeepInv` `Deep Learning` `Optimisation`
